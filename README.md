# Code4Nature — Demo README

This repository contains simple demo files for the Code4Nature project.

Files added:
- engine.js — a minimal Express.js server (run with `node engine.js`).
- main.py — a minimal Python entrypoint demo (run with `python3 main.py`).

How to run the demos:

Node (engine.js):
1. Install dependencies: `npm init -y && npm install express`
2. Start the server: `node engine.js`
3. Open http://localhost:3000 or check health at http://localhost:3000/health

Python (main.py):
1. Run: `python3 main.py`
